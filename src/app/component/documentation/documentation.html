📋 Core Gameplay

Rules (click to expand)

The Goal

  • Each row must add up to the gray number at the left of that row.
  • Each column must add up to the gray number at the top of that column.
  • Each color group must add up to the tiny number in that group's top-left cell.

The correct solution is the only way to satisfy all three rules at once.

Beginner's hint • If a row must total 2, you can immediately hide any numbers larger than 2 in that row. Use this logic to whittle away unusable numbers, thus slowly revealing required numbers.

Gameplay

  1. Remove cells • Swipe down or double-tap (or right-click on desktop) to remove a number — “this number cannot be part of the solution.”
  2. Select required cells • Tap or swipe up on a cell to select (circle) it — “this number must be part of the solution.”
  3. Mistake warning • If you try to select a number that doesn't belong or remove a number that is required, the cell will wiggle and Mistakes counter will increase. Unless in tournament mode, the game will not let you make an incorrect move... It will simply warn you that a move is incorrect.


🎲 Guessing

Guessing is almost never required.

Any board not labeled with an report_problemFP+ warning (FP+ meaning) is guaranteed to be solvable without a single guess. In fact, game #422 is the first game to require a guess, and even that isn't until only the last 6 unselected cells remain.

In the case of #422, when only the last 6 cells remain, by enabling tournament mode in the settings, one of the two equally correct solutions can be chosen without fear of ruining a winning streak.

That said, given how boards are randomly generated, there is a possibility a completely unsolvable board does exist.


✨ App Features

  • Scratch pad • It's just a handy spot to park a single number, just like you would with pencil and paper. Nudge it up or down with the buttons, and double-click the value to reset it back to 10 when you want to start fresh.
  • report_problemFP+ #-# • This warning appears on only 3.4% of boards. It indicates that a board cannot be solved using only first-principles logic (identifying required and unusable cells based solely on their presence in a row, column, or group). The #-# shown in the warning represents how many cells [can't]-[can] be determined with first-principles alone. Beyond that point, more advanced deduction methods are required to solve the board. Though as mentioned, guessing is almost never required.
  • Temporary highlight • Long-press a cell until the magnified view appears, then — without lifting your finger — slide slightly left or right to toggle on or off the red/white diamond highlight over a cell. Use these highlights as a marker to help you keep track of numbers you're actively considering.
  • Magnify • Long-press and hold a cell to magnify the cell content (useful for viewing tiny text on smaller screens).
  • Par Time • This is the amount of time the game thinks it would take for a seasoned veteran to solve the displayed board. Click through the stats to see your time on each board, and how your speed compares.
  • Stat toggles • Some of the stats are surrounded by < > indicating they can be clicked to display different stats.
  • Skip and return • Use the buttons beside the game number to jump past a tricky board. Your progress is saved automatically, so you can resume a partially completed puzzle any time.
  • undoUndo in the more_vert menu • Ah yes, the Undo button — your safety net for when the game occasionally misreads a gesture (or when your finger slips because snacks are involved).

    Sure, you could use it to quietly erase mistakes and stretch out that precious winning streak… but let's be honest, Tony's mom would roll her eyes and remind you: You're only cheating yourself.

    So, use Undo when the game messes up. Abuse it, and hey — that victory will taste about as authentic as a dish of tagliatelle al tartufo from a gas station.
  • Sessions • Found on the on the session page and from the more_vert app menu. Allows for tracking stats achieved during a specified time period only.
  • Start board over • Found in the more_vert app menu. Does what it says.
  • Tournament Mode • App doesn't warn when mistakes are made. Note, a board with uncorrected mistakes cannot be completed. See more details in the settings.
  • Difficulty • Relative difficulty of a board on a 0-100 scale.
  • Shapes mode • Accessibility option for players with colorblindness. See more details in the settings.
  • Spot running totals • The upper-right corner of each header cell can show the sum of the currently selected cells in that section. You can disable this display from the settings menu if you like making things more difficult than they need to be.

📲 Installing (Optional)

Somebers is a Progressive Web App (PWA). You can simply use it in your browser, or you can optionally “install” it to get a more app-like experience. Installation is not required — gameplay is identical — but installed PWAs:

  • Launch faster from your home screen, Dock, or Start menu.
  • Run in a standalone window without the browser address bar.
  • Work in airplane mode and in internet dead zones.
Note: Exact steps differ by platform and browser. Follow the instructions for your setup below.

For best results on iOS, use Safari.

  1. Open Safari and navigate to https://somebers.com.
  2. Tap the Share button (you may need to click the ... menu button to find the share option)

Android

  • Chrome: Visit somebers.com → in the upper RIGHT part of the screen tap Chrome's ⋮ menu → Install app (or Add to Home screen), then confirm.

If given the option, choose Install instead of “Add to Home screen” for the best PWA experience.

You may also see an automatic “Install” prompt banner in supported browsers.

macOS

  • Safari: Open somebers.com → from the File menu select Add to Dock (or use the Share button → Add to Dock), then choose to open in a separate window.
  • Chrome: Open somebers.com → click the Install icon in the address bar (or ⋮ menu → Save and share → Install page as app…), then confirm.

Windows

  • Chrome: Open somebers.com → click the Install icon in the address bar (or ⋮ menu → Install), then confirm.
  • Edge: Open somebers.com → ⋮ menu → Apps → Install this site as an app.

Safari is not available on Windows; use Chrome or Edge.

After installing, launch Somebers from your home screen, Dock, or Start menu. If you prefer using your browser, that’s great too — installation is completely optional.
